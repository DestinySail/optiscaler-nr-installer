# OptiScaler NR Installer 0.1.3

取消游戏文件备份和上一版本快照，避免每次更新额外占用约 0.5 GiB。

- 更新时先清理旧注入目录和旧版本残留，再安装新组件。
- 卸载删除本项目安装记录中的全部注入文件，游戏目录不再恢复上一版本或安装前快照。
- 原来的“回滚”入口已合并到“卸载”；卸载结果为无本项目注入的普通游戏目录。
- 安装失败时删除本次写入的注入文件，不保留旧版本副本。
- 首次运行 0.1.3 时删除旧版本留在 `%LOCALAPPDATA%\OptiScalerNR\backups` 的游戏文件快照。

固定方案、资源版本、游戏发现和兼容范围与 0.1.2 相同。安装器自身的 EXE 自更新仍保留上一版安装器文件，体积约 11 MiB。
