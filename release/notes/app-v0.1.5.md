# OptiScaler NR Installer 0.1.5

- 重做安装器界面：放大首页文字，移除大幅占位宣传区域，列表至少显示五款游戏，统一卡片和底部操作区域留白。
- 游戏发现期间显示加载状态，避免先显示“没有游戏”；区分安装器与主包组件的更新状态。
- 启动自动检查更新；上游卡片可下载并校验主包，已安装游戏显示“更新到此游戏”。
- 更新检查改为自有签名静态清单，不再在客户端调用 GitHub Releases API。自动检查缓存 1 小时，失败冷却 5 分钟，可使用已验签旧缓存。
- 新主包校验成功后清理旧版主包缓存，不重复下载未变化的固定资源。
- 固定安装方案、主包/模型兼容性检查及游戏文件保护逻辑保持不变。

静态更新清单由维护端定时发布；新上游发布不等于所有游戏已完成兼容性验证。GitHub/下载网络仍可能暂时不可用。
