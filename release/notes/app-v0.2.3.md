# OptiScaler NR Installer 0.2.3

- 安装时可选择 310.8.0 原模型（FP8 + INT4）、310.9.16 新模型（Small），或两个都安装。
- 只下载、校验和部署所选模型；双模型首次安装默认启用 Small，已有配置保留当前模型选择。
- 修复及维护更新沿用每个游戏的模型记录，更换安装选项时清理旧的受管模型文件。
- 新模型要求支持 Small 的主包；不支持的主包会在部署前被拒绝。
- 防止导入主包中的模型文件覆盖已经校验的模型。

310.9.16 源 DLL 中的原模型与 310.8.0 相同，新增的是 Small；Small 暂不支持 INT4。双模型安装后可在游戏内切换。

验证：50 项自动测试、Clippy、Release 构建，以及真实 v1.13.3 组件在临时目录内的三种模型安装、检查、修复和卸载均通过。已验证 Small 的公开下载、完整 SHA-256 和 Range 响应；未进行游戏内画质、性能或稳定性验证。
