# OptiScaler NR Installer 0.2.5

- 与 0.2.4 相同的四段版本号支持（`v1.13.3.3` 等主包版本可正常更新）。
- 发布流程新增上游版本固定开关，可在过渡期让老客户端继续读到可解析的目录并弹窗升级安装器。

0.2.3 及更早版本无法解析含四段版本号的更新目录，会退回本地缓存而不提示安装器更新。目录暂时固定上游为 `v1.13.3` 后，这些版本可以正常看到并升级到 0.2.5；升级完成后删除仓库变量 `NR_CATALOG_UPSTREAM_TAG`，目录会恢复跟随上游最新版本（`v1.13.3.3`）。

过渡期间目录里的主包仍是 1.13.3；已安装 1.13.3.3 的用户不会被降级。

验证：51 项自动测试、Release 构建，以及目录签名和版本回读。
