# 兼容范围

## 硬件

正常安装只放行 AMD RDNA4 独立显卡：

- Navi 48：`0x7550`、`0x7551`
- Navi 44：`0x7590`
- 设备名称包含 `RX 9070` 或 `RX 9060` 的设备

软件适配器和多显卡环境中的其他适配器会显示出来，但不会单独满足安装条件。其他 AMD 显卡不会只因为厂商 ID 是 AMD 就被放行。

## 游戏

| 游戏来源 | 发现方式 | 游戏内 NR + XeFG |
|---|---|---|
| 鸣潮（WeGame） | 从卸载记录定位 Win64 主程序 | 需要自行验证 |
| Steam 库中的 64 位候选游戏 | 扫描库清单 | 需要自行验证 |
| Epic 清单中的候选游戏 | 扫描安装清单 | 需要自行验证 |
| 手动选择的游戏 | 用户选择主程序 | 需要自行验证 |

自动发现只说明程序找到并判断了一个可能的游戏 EXE。它不等同于该游戏已经适配固定方案。

## 方案前提

- 游戏使用 D3D12。
- 游戏提供本方案所需的 DLSSG/Streamline 帧生成输入。
- 游戏目录允许写入。
- 常用代理文件名没有冲突；已有 OptiScaler 代理会被接管，其他第三方 DLL 不会被静默覆盖。

## 游戏内检查

1. 开启游戏自带的 DLSS 帧生成。
2. 按 `Insert` 打开 OptiScaler。
3. 确认 `NrBackend=mochizuki`。
4. 确认帧生成输出为 `XeFG`。
5. 首次进入场景后重启游戏，使 `HighResMV=true` 生效。

联网游戏出现反作弊提示时必须停用本方案。本项目不提供反作弊绕过。
